# Crime Analysis Dashboard

## 📊 Project Overview

The **Crime Analysis Dashboard** is an interactive Power BI dashboard designed to analyze crime cases, trends, locations, severity, arrests, case status, response time, and resolution performance.

The dashboard transforms raw crime data into meaningful insights using KPIs, interactive visualizations, slicers, and dynamic executive insights.

## 🎯 Business Problem

Crime data can be difficult to analyze when presented as raw records or spreadsheets. Management needs an interactive way to understand crime patterns and monitor case performance.

This dashboard helps answer questions such as:

- How many crimes were reported?
- Which crime types occur most frequently?
- Which states and cities have the highest crime volume?
- Is crime increasing or decreasing over time?
- What percentage of cases resulted in arrests?
- How many cases remain open?
- Which crimes have the highest severity?
- What is the average police response time?
- What is the average resolution time?
- Which locations require the most attention?

## 🧹 Data Cleaning Process

The dataset was prepared using Power Query.

Key steps included:

1. Importing the dataset into Power BI.
2. Checking and correcting data types.
3. Handling missing and blank values.
4. Removing unnecessary columns.
5. Checking for duplicate records.
6. Standardizing categorical values.
7. Cleaning date fields.
8. Creating calculated and conditional columns where required.
9. Preparing the final dataset for analysis.

## 📊 Dashboard Features

### KPI Analysis

The dashboard provides key metrics such as:

- Total Crimes
- Total Arrests
- Open Cases
- Resolved Cases
- Arrest Rate
- Average Response Time
- Average Resolution Time

### Crime Trend Analysis

Crime activity is analyzed over time to identify increases, decreases, and recurring patterns.

### Crime Type Analysis

Crime categories are compared to identify the most frequently reported types of crime.

### Location Analysis

Crime cases are analyzed by state and city to identify areas with higher reported crime volumes.

### Severity Analysis

Crime severity is analyzed to identify cases and crime categories associated with different severity levels.

### Arrest and Case Status

The dashboard analyzes arrested, non-arrested, open, closed, and resolved cases.

### Response and Resolution Analysis

Average police response time and case resolution time are analyzed to provide insight into operational performance.

## 💡 Dynamic Executive Insights

The dashboard includes a Dynamic Executive Insights section that automatically highlights important patterns from the data.

The insights can identify:

- Changes in crime volume
- Most frequent crime types
- High-crime locations
- Arrest performance
